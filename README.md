# Healthcare ML - Diabetes Prediction

This project focuses on predicting diabetes using machine learning models and healthcare data.

## Project Overview
The goal of this project is to compare different machine learning models for diabetes prediction and analyze feature importance.

## Dataset
Public diabetes dataset containing healthcare-related features.

## Machine Learning Models
- Logistic Regression
- Random Forest

## Features
- Data preprocessing
- Feature scaling
- Model evaluation
- Feature importance analysis (Explainability)

## Technologies
- Python
- pandas
- scikit-learn

## Future Work
In future work, this project can be extended using deep learning and medical imaging datasets such as mammography.
## Results

This project compares Logistic Regression and Random Forest models for diabetes prediction.

Feature importance analysis was used to improve model interpretability and identify the most influential healthcare variables.
